A QUICK SOUND CHECK

A few notes on tuning.

  1. Choose a tuning, then press Start tuning and allow microphone access.
  2. Pluck one string near your microphone. Auto detect finds the nearest string; select a string to lock onto it.
  3. If the pitch is flat, tighten gently. If it’s sharp, loosen. Aim for the green center, within ±5 cents.
  4. Use Play to hear a reference tone. Microphone readings pause while the tone plays.

Chromatic mode follows any note. Microphone access requires localhost or HTTPS. Your audio is processed on this device and is never recorded or uploaded.
